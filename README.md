SkillSwap is a “skill exchange platform” — it is like a mini LinkedIn + marketplace.
But instead of money, people trade skills.

Backend (Spring Boot)

REST APIs (auth, users, skills, sessions)
JWT security + roles (user/admin)
database design + ER modeling
transactions, caching, scheduling
WebSockets (real-time chat)
email notifications

Frontend (React)

multi-page SPA (Home, Profile, Chat, Admin, etc.)
auth context + protected routes
Redux state management
API integration + dashboards
